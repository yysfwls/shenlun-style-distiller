# 五层分析方法

## 分析前：三方归因

任何候选规律都先接受三个问题：

1. 这是题目或给定材料直接要求的吗？
2. 这是多数申论范文共有的惯例吗？
3. 它是否在该作者不同题型、主题或时期的多篇文章中重复出现？

只有第 3 项有证据，并能排除前两项时，才标为作者稳定特征。无法排除时标为“混合来源”或“待验证”。

## L1 语言表达

分析标题、词语、句式、句长、标点、修辞、连接词、段落长度和节奏。统计时分别处理：

- 材料原句或高度近似表达；
- 政策固定表述；
- 申论通用套语；
- 作者可能的稳定表达。

词频高不等于有辨识度。优先寻找相对另一作者或同类范文更突出的表达组合，并记录其出现范围。输出 `language-dna.md`。

## L2 篇章结构

按段落功能而非只按段数标注：题目解释、背景、中心论点、分论点、释义、材料例证、材料外案例、原因、意义、对策、过渡、回扣和收束。

分析标题生成方式、开头进入中心论点的方法、中心论点与分论点的关系、单段论证推进、段间衔接和结尾回扣。按题型分别归纳模板，不把某道题的结构推广为通用公式。输出 `structure-templates.md`。

## L3 审题立意

对照题目、材料和范文，重建作者如何解释关键词与关系、选择中心论点的抽象层级、从材料归纳分论点，以及如何处理意义、问题、原因、对策和辩证关系。只有讲解明确表达时，才把某条路径标为作者主动回避。没有题目和材料时，不声称已还原审题过程。输出 `thesis-generation.md`。

## L4 素材与论证

为论据标注来源：直接复述材料、压缩材料、跨材料综合、材料外公共案例、政策表述、领导人讲话、名言典故、历史案例、数据或抽象道理。

同时标注功能：引出论点、解释概念、证明意义、揭示问题、分析原因、支撑对策、完成转折或抬高结尾。重点分析材料如何被压缩、重组、抽象和回扣，而不是只列引用清单。未经核验的名言、数据和政策原文不得作为可复用规则。输出 `evidence-strategy.md`。

## L5 申论认知框架

从跨篇稳定的论证决策中归纳主体关系、结构原因与主体责任、公共价值排序、个体现象如何上升为治理问题，以及常用因果模型、矛盾模型和行动模型。

区分作者明确讲解、范文表现和分析者推断。用“在本语料范围内表现出”限定结论，不推断作者完整人格或私人信念。输出 `cognitive-framework.md`。

## 证据记录格式

每条规则使用统一结构：

```markdown
### 规则名称

- 层级：L1-L5
- 类型：作者稳定 / 题型限定 / 主题限定 / 时期限定 / 混合来源 / 待验证
- 观察：语料实际出现了什么
- 归因：为什么可归因于作者，或为什么暂不能归因
- 适用范围：适用的题型、主题和条件
- 覆盖：命中篇数 / 可比较篇数
- 证据：案例编号与具体段落功能
- 反例：案例编号，或“尚未观察到；不能视为不存在”
- 置信度：高 / 中 / 低
- 写作指令：未来如何执行
- 误用边界：什么时候不能机械套用
```

高置信度通常要求跨多篇、跨主题复现，且有直接文本或讲解证据；中置信度允许范围受限；低置信度只作为待验证假设，不进入默认写作指令。

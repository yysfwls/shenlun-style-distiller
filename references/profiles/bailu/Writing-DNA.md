# 白鹭课程体系 Writing DNA

版本：v1.1（2026-08-22）  
语料：6篇课程参考范文（BL-001—BL-006）  
适用：申论大作文审题、关系型立意、机制型论证和成稿检查。

## 限制

这是一份“白鹭课程体系”画像，不是亲笔鉴定。6份手写答题卡和16篇外部好文没有计入语言统计。样本仅6篇，因此按题型扩展时必须保守。

## 核心写作算法

```text
解释题干概念
→ 判断概念间的条件、互构或反馈关系
→ 从材料中提炼重复机制
→ 形成2—3个互有关联的分论点
→ 每段用“解释—材料—推导”证明机制
→ 结尾重新合并关系并回到公共价值
```

## 核心执行规则

| 规则编号 | 写作指令 | 适用范围与边界 |
|---|---|---|
| `BL-L2-001` | 开头先解释题干概念或关系，再提出中心判断。 | 抽象题、关系题优先；不要把定义写成空泛释义。 |
| `BL-L2-002` | 先建立题意和机制，再写对策；分论点回答不同机制环节。 | 不为追求深度强造材料无法支持的反馈关系。 |
| `BL-L3-001` | 双主题先判断条件、互构或反馈关系。 | 只在题干和材料确实支持双向关系时使用。 |
| `BL-L3-002` | 从多则材料的共同机制生成分论点，不直接套三分法。 | 缺少完整材料时降级为探索性提纲。 |
| `BL-L4-001` | 将材料压缩为“主体＋动作＋结果”，多案例并置后明确推导。 | 案例必须承担证明功能，不能只罗列名称。 |
| `BL-L1-001` | 用中长句承载关系，用短句压缩判断。 | 主谓和层次必须清楚，不为风格牺牲可读性。 |
| `BL-L1-002` | 使用“可见、故而、因此”等完成逻辑落点。 | 控制密度，不把连接词当作论证本身。 |
| `BL-L1-003` | 若使用隐喻，一篇维持一套同源隐喻。 | 中置信度倾向；隐喻服务结构，不代替论证。 |
| `BL-L5-002` | 结尾重新合并关系，并落到发展质量、法治或人民福祉。 | 不在结尾新增分论点。 |

详细证据、反例和置信度见 [规则证据索引](reports/rule-evidence-index.md)。

## 题型路由

- 关系型：A创造B的条件，B反哺A，最终形成循环。
- 抽象概念型：定义主题，依次回答目标、方法、取舍或机制。
- 治理/执法型：内在认识与素养＋外在方法与能力＋知行统一。
- 明确策论文：保留机制分析，但把分论点改造成可执行措施，避免纯哲学展开。

## 语言参数

- 句式：中长句为主，段末允许一组对称短句。
- 转折：优先逻辑推导，不机械使用序数词。
- 词汇：联系、发展、统筹、转化、反哺、迭代等关系和过程词。
- 修辞：关键词加引号、同源隐喻、克制的典故和哲学概念。

## Do

- 先画出题干关系图和材料机制表。
- 让每个案例承担明确证明功能。
- 让分论点之间发生联系。
- 用具体公共价值收束抽象分析。

## Don't

- 不把哲学术语当作万能高级感。
- 不连续堆叠无关比喻和四字词。
- 不为追求长句牺牲可读性。
- 不从6篇样本推断所有题型都应采用同一结构。

## 生成前检查

题目要求和材料事实是否已经独立确认？中心关系是什么？每个分论点由哪些材料支持？哪些规则只是低置信度倾向？

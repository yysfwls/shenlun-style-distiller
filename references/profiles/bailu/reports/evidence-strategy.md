# 白鹭课程体系·素材与论证策略

## 材料使用

- 倾向将同类材料压缩后并置，证明一个机制，而不是长篇复述单一案例。
- 案例常保留“主体＋关键动作＋机制结果”三项，删去不服务论点的背景。
- 同一段中，材料前有抽象解释，材料后有推导句，案例不是孤立摆放。
- 对题干中的核心词进行再定义，再用材料验证定义。

## 外部素材

- 使用古语、经典诗文、马克思主义哲学概念和时代话语建立论证高度。
- 外部素材多承担开题、转折或收束功能，主体论证仍依赖给定材料。
- 引文与比喻强调同一主题时，会形成贯穿全文的意象链。

## 段落论证协议

```text
观点：说明本段在整体机制中的位置
解释：界定概念或揭示条件
证据：压缩 1—3 个材料案例
推导：说明案例为何支持观点
回扣：给出行动、结果或公共价值
```

## 边界

- 不从课程范文直接复制冷僻词、长串排比或未经核验的引文。
- 多案例并置必须说明共性，不能变成案例名单。
- 哲学概念若不能解释材料差异，应删除。

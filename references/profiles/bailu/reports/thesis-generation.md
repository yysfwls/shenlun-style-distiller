# 白鹭课程体系·审题立意与论点生成

## 主要方法

1. **先解释关系，不急着列对策。** 面对双主题或关键词题，先判断因果、条件、互构或反馈关系。
2. **把题干概念机制化。** “融合”被拆成融和与融活；“流动与新生”被解释为要素流动、形态新生及反向吸引。
3. **加入哲学层的判断工具。** 常使用联系、发展、矛盾、内外因、认识与实践等框架，但最终必须落到材料。
4. **从材料共性上升，而非逐段复述。** 多个案例被压缩为一种机制，再由机制生成分论点。
5. **分论点之间存在关系。** 分论点不是三个同义对策，通常分别回答条件、运行方式、反馈或价值。

## 生成步骤

```text
圈定题干概念
→ 判断概念间关系
→ 从材料提取重复机制
→ 选择一个能统摄材料的抽象层级
→ 形成 2—3 个互有关联的分论点
→ 检查每个分论点是否有材料证据
```

## 适用题型

- 双主题、关系型题；
- 抽象概念型题；
- 要求“深入思考一句话”的题；
- 材料案例多、需要提炼机制的题。

## 不宜机械使用

对于明确要求策论文、对策必须细化的题目，不应只做哲学解释。哲学概念必须帮助区分材料和生成论点，不能成为脱离题目的装饰。

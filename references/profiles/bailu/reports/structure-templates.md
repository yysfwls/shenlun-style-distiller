# 白鹭课程体系·文章结构模板

## 稳定结构

6 篇范文都不是简单的“开头＋三个同构分论点＋结尾”。更稳定的结构是：

```text
解释题干或建立时代背景
→ 把题目上升为一个关系或机制
→ 给出中心判断
→ 用 2—3 个机制段展开
→ 在结尾重新合并关系并回到发展目标
```

## 开头

开头通常完成两步：

1. 从古语、哲学命题、历史纵深或现实趋势解释题干；
2. 把题干改写成可论证的机制，并提出中心判断。

BL-001、BL-002使用“解释命题＋现实任务”；BL-003至BL-006更偏向“哲学/历史框架＋关系重构”。

## 正文

常见正文段内部结构：

```text
带方向和结果的分论点
→ 概念释义或机制解释
→ 题内材料压缩/多案例并置
→ 从案例推出条件、方法或边界
→ 以逻辑判断回扣分论点
```

正文的关系组织主要有三种：

- 二元互构：融和与融活、流动与新生；
- 认识—实践：认识论与方法论、知与行；
- 决策链：目标—方法—取舍，基础—机遇—循环。

## 结尾

结尾一般不新增对策，而是：

- 重新合并中心关系；
- 回扣开头的哲学、历史或自然意象；
- 把个别材料提升到高质量发展、法治或未来治理；
- 使用一组对称句形成音势。

## 可复用模板

### 关系型题目

```text
历史/现实入口 → 界定 A 与 B → 指出二者不是简单并列
→ A 如何为 B 创造条件 → B 如何反哺 A
→ 合并为循环机制 → 回扣公共价值
```

### 单主题抽象题

```text
界定主题的时代意义 → 提出中心判断
→ 明目标 → 讲方法 → 懂取舍/建机制
→ 以知行统一收束
```

### 执法/治理题

```text
解释规范命题 → 落到现实任务
→ 内在认识/素养 → 外在方法/能力
→ 知行合一 → 百姓福祉和治理目标
```

# 白鹭课程体系·申论认知框架

以下结论只描述 BL-001 至 BL-006 的课程范文表现。

## 稳定认知倾向

1. **发展是过程而非静态结果。** 变化、流动、融合、创新都被放在演化过程里理解。
2. **关系优先于孤立要素。** 强调联系、条件、反馈和互构，反对简单嫁接或单点归因。
3. **认识与实践相互校正。** 目标、方法和行动构成完整链条；知行合一是多篇文章的深层结构。
4. **长期价值高于短期波动。** 面对不确定性，强调韧性、能力、长期投入和结构升级。
5. **政府兼具规范、服务和引导功能。** 既要建规则，也要创新方法、链接资源、回应群众。
6. **公共价值以发展质量和人民福祉收束。** 抽象机制最终落到法治、公平、民生或高质量发展。

## 常用判断模型

- 联系模型：要素只有在条件和机制中结合，才产生新效能。
- 发展模型：新事物通过迭代、扬弃和创新形成。
- 反馈模型：结果反过来增强资源吸引和发展能力。
- 知行模型：认识确定方向，实践检验并提升认识。
- 长期模型：短期困难是长期演化中的局部阶段。

## 使用提醒

这些模型是写作决策工具，不等于作者完整个人世界观。应用时每个模型都必须能解释题目材料。

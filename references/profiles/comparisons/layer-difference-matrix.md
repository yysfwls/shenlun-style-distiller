# 白鹭与袁东课程体系·分层差异矩阵

| 层级 | 白鹭课程体系 | 袁东课程体系 | 证据说明 |
|---|---|---|---|
| L1语言 | 长句、概念词、同源隐喻、逻辑推导 | 中等句长、必要条件句、显性行动词、同构句式 | 白鹭6篇；袁东77篇＋方法讲义 |
| L2结构 | 关系/机制展开，分论点相互关联 | 四类题型路由，分论点并列清楚 | 袁东分类为明确教学规则 |
| L3立意 | 先重构概念关系，再从材料提炼机制 | 先定题型与主题数量，再生成总论点和三分点 | “流动与新生”有同题立意证据 |
| L4论证 | 概念解释＋多材料压缩＋推导 | 要素/事例/名言分类＋显式回扣 | 两者都重材料，但组织方式不同 |
| L5认知 | 联系、发展、反馈、知行、长期价值 | 问题行动化、工具组合、公共价值可见 | 只代表课程文本表现 |

## 最核心差异

白鹭更像“先建解释模型，再组织材料”；袁东更像“先确认题型和阅卷骨架，再把材料装入稳定结构”。前者优势是立意深度和关系分析，后者优势是成文稳定性和结构可见度。

## 数据差异

- 白鹭平均句长48.4字，袁东38.5字。
- 白鹭`可见`覆盖4/6、`故而`覆盖3/6；袁东`只有`覆盖47/77、`才能`覆盖55/77、`必须`覆盖34/77。
- 白鹭核心样本只有6篇，差异判断的置信度低于袁东。

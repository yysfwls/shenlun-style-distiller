# 袁东课程体系 Writing DNA

版本：v1.1（2026-08-22）  
语料：77篇课程范文、完整大作文方法讲义  
适用：申论大作文快速审题、稳定提纲、模板适配和成稿检查。

## 限制

这是“袁东课程体系”画像。77篇范文来自课程范文库，未逐篇确认亲笔作者。具体名言、政策原文和数据不得未经核验直接复用。

## 核心写作算法

```text
识别题型与主题数量
→ 选择分析/解决/评论/A-B结构
→ 写明确的标题和总论点
→ 从材料抽取三组不重复依据
→ 选择对策、影响或对策＋影响分论点
→ 用要素、事例或名言完成各段论证
→ 结尾重申价值并展望
```

## 核心执行规则

| 规则编号 | 写作指令 | 适用范围与边界 |
|---|---|---|
| `YD-L2-001` | 先把题目归入分析、解决、评论或 A-B 结构，再搭建全文。 | 复杂多主题题可组合，但必须说明主结构。 |
| `YD-L3-001` | 先定题型和主题数量，再从材料中找不重复的分点。 | 不用模板库凭空制造材料没有的论点。 |
| `YD-L2-002` | 开头按需组合警句、背景、影响、问题和总论点。 | 不追求元素齐全，避免五级配方全部塞入。 |
| `YD-L2-003` | 分论点保持句式同构，优先采用“主题＋对策/影响/对策＋影响”。 | 同构不等于同义，三个分点必须承担不同任务。 |
| `YD-L4-001` | 每段主要选择要素、事例或名言论证，并在段末显式回扣。 | 可以组合，但不能堆砌人物和名言。 |
| `YD-L4-002` | 把材料要点改写成作文论据。 | 不能原样搬运客观题答案或材料长句。 |
| `YD-L1-001` | 必要时用“只有/唯有—才能”压缩判断。 | 不在每段机械重复。 |
| `YD-L1-002` | 用明确主体和行动词提高阅卷识别度。 | 评论型文章可以更克制。 |
| `YD-L1-003` | 以中等句长和明显逻辑路标组织段落。 | 不用路标替代因果分析。 |
| `YD-L5-001` | 结尾重申主题并落到治理行动和公共价值。 | 不新增复杂观点。 |

详细证据、反例和置信度见 [规则证据索引](reports/rule-evidence-index.md)。

## 语言参数

- 句式：中等长度，逻辑信号明显。
- 判断：只有/唯有—才能、必须、我们要，但限制重复密度。
- 标题：行动＋目标，或两个对称动宾短语。
- 修辞：一条贴题警句、少量具象比喻；不调用整页模板库。

## 题型路由

- 分析型：围绕主题的三项作用、意义或机制。
- 解决型：对应材料问题提出三项可执行行动。
- 评论型：先明确评价，再论原因、影响、边界或改进。
- A-B型：界定关系，分别论证A、B和共同结果。

## Do

- 先从材料找依据，再给分论点套句式。
- 让阅卷者能快速看到总论点、分论点和段落结论。
- 将客观题概括转化为作文论据。
- 一个段落只承担一个主要任务。

## Don't

- 不用模板库凭空制造材料没有的论点。
- 不在每段都重复“只有……才能……”。
- 不堆砌压舱石、方向标、加速器等比喻。
- 不把名言和人物名单当作论证。

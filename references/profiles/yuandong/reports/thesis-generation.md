# 袁东课程体系·审题立意与论点生成

## 明确教学规则

袁东体系把立意拆成可操作步骤：确定题型和主题，生成标题与总论点，再从材料关键词、题干关系和常见治理要素中寻找分论点，最后统一分论点句式。

## 立意路径

1. 单主题题先判断写意义还是写对策。
2. 双主题题解释A与B的关系，避免分别写成两篇文章。
3. 多主题题寻找能统摄多个词的上位目标或共同机制。
4. 总论点倾向明确回答“要不要做、做什么、为了什么”。
5. 分论点可来自材料中的不同主体、不同措施、不同影响或不同环节。

## 可执行步骤

```text
识别单主题/双主题/多主题
→ 判断分析型/解决型/评论型/A-B型
→ 写出一句行动明确的总论点
→ 从材料中寻找三组不重复的依据
→ 选择“对策、影响、对策＋影响”句式
→ 检查三点能否共同推出总论点
```

## 同题证据：流动与新生

课程讲义给出的总论点是“加速流动才能创造新生并推动高质量发展”，分论点围绕流动拓展空间、流动带来机遇、新生反向促进发展等方向。其特点是快速固定因果主轴，再把材料装入并列分点。

## 边界

讲义中的主题词库和分论点模板只能用于候选生成。最终分论点必须能指向给定材料，不能根据模板凭空增加“人才、科技、制度”三件套。

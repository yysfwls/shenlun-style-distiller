# 袁东课程体系·文章结构模板

## 四种主结构

77篇范文赏析明确标注：

- 分析问题型：42篇；
- 解决问题型：25篇；
- 评论型：5篇；
- 论证A与B型：5篇。

这说明结构选择先服从题型，而不是所有文章都套一种三分法。

## 开头五级配方

方法讲义给出五种由简到繁的开头：

1. 名言警句＋影响＋过渡＋总论点；
2. 名言警句＋背景＋影响＋过渡＋总论点；
3. 名言警句＋影响＋问题＋过渡＋总论点；
4. 名言警句＋背景＋影响＋问题＋过渡＋总论点；
5. 名言警句＋背景＋影响＋成绩＋问题＋过渡＋总论点。

实际应用不应追求元素越多越好，应根据字数、题型和材料选择最短够用版本。

## 分论点三种样式

```text
总论点主题＋对策
总论点主题＋影响
总论点主题＋对策＋影响
```

三个分论点强调同构和并列可见性。常用槽位包括“在……上下功夫”“以……为抓手”“需要……，实现……”。

## 单段论证

方法讲义把论证来源分为要素论证、事例论证和名言警句论证，并给出复合段落：

```text
名言/判断
→ 说明影响
→ 指出问题
→ 用材料案例或对策展开
→ 回扣分论点及结果
```

## 结尾

常用结构是“名言警句＋意义/必要性＋行动或未来展望”。结尾重申总论点，并把分论点提升到国家发展、人民幸福或治理现代化，不新增复杂分析。

## 题型路由

- 分析问题型：主题意义/作用作为三个分论点。
- 解决问题型：针对材料问题形成三项行动。
- 评论型：明确评价，再从原因、影响、边界或改进展开。
- A与B型：先界定关系，再分别论证A、B及其共同结果。

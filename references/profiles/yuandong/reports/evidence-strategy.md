# 袁东课程体系·素材与论证策略

## 明确分类

课程将论证来源分为：

- 要素论证：从给定材料或客观题答案中提取主体、措施和影响；
- 事例论证：使用材料案例或积累的经典人物/事件；
- 名言警句论证：用于开头、段首、转折或结尾。

## 材料转化

1. 把客观题中的概括要点改写成分论点或案例链。
2. 案例压缩为主体、行动、效果，随后回扣分论点。
3. 多个案例常用排比或并置呈现，强化论据密度。
4. 论证结尾使用“因此、可见、唯有”等显式推出行动或价值。

## 素材库使用

讲义提供主题化名言、经典人物、治理案例和政策表述。正确用法是先确定段落功能，再选择一条最贴合的素材；不能先选名言再倒推观点。

## 推荐段落协议

```text
分论点
→ 必要性或问题
→ 1—2个材料/公共案例
→ 解释案例与观点的因果关系
→ 对策或价值回扣
```

## 风险控制

- 具体名言、数据和政策原话使用前重新核验。
- 素材库中的占位符、缩写和课程脱敏符号不能进入成稿。
- 一个段落不同时堆叠名言、三个人物、三项政策和多个比喻。
- 课程范文的成句不能整段迁移到新题。

# 袁东课程体系·申论认知框架

以下是课程教学与77篇范文表现出的写作判断，不等于老师完整个人世界观。

## 稳定倾向

1. **问题应转化为行动。** 总论点和分论点偏好明确的必要性、对策和结果。
2. **公共价值必须可见。** 多数文章最终落到人民、群众、发展、治理效能或国家目标。
3. **结构服务阅卷识别。** 观点、分点和段落功能以显性语言呈现，减少读者推断成本。
4. **治理依赖组合工具。** 法治、科技、人才、服务、制度和多元主体协同是常见行动变量。
5. **发展叙事强调突破与落实。** 创新解决瓶颈，实干把目标转成结果，制度保障持续性。
6. **价值与工具相连接。** 民生、向善、公平等价值通常被翻译为具体治理措施。

## 常用模型

- 必要条件模型：只有采取X，才能实现Y。
- 问题—对策模型：问题造成损害，针对性行动修复结果。
- 主体协同模型：政府、社会、市场和群众共同参与。
- 工具组合模型：制度规范＋技术赋能＋服务优化。
- 价值落点模型：对策最终提高获得感、幸福感、安全感或发展质量。

## 适用边界

该体系适合时间紧、需要稳定成文和结构清楚的场景。面对高度抽象关系题时，应增加概念解释，避免仅将三个模板化对策并列。

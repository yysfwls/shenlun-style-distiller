# 袁东课程体系·应用检查表

- 是否先判断了分析型、解决型、评论型或A-B型？
- 标题是否直接包含主题、行动或目标？
- 总论点是否明确回答做什么、为什么？
- 三个分论点是否语法同构但内容不重复？
- 每个分论点是否能在材料中找到依据？
- 开头是否只使用必要元素，没有把五级配方全部塞入？
- 段落是否选定了要素、事例或名言中的主要论证路径？
- 案例后是否解释了它为什么能证明观点？
- `只有、才能、必须、我们要`是否过密？
- 抓手、纽带、压舱石等比喻是否同质化或错配？
- 名言、政策表述、数据是否已经核验？
- 结尾是否重申主题并展望，没有新增分论点？
- 是否残留占位符、脱敏符号或讲义原句？
